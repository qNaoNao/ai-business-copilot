# 工程设计与验收

更新日期：2026-10-08。AI Business Copilot 是单 Agent 经营分析应用，
结合确定性 SQL 工具、本地知识检索和可恢复工作流。目前运行于本机，未部署公开在线服务。

## 实现范围

原有月度指标、品类/SKU 下钻、多轮提问、图表、历史和报告能力保持不变。
工程升级补充检索证据、节点执行状态、恢复机制和可复现测试。

| 能力 | 实现 | 边界 |
|---|---|---|
| LangGraph 工作流 | retrieve → model/plan → tools → model → verify；SQLite 检查点 | 单 Agent，不包含多 Agent 协作 |
| 恢复 | 复用已保存节点结果与所选品类/SKU，继续未完成节点 | API 返回与检查点提交之间的崩溃窗口可能导致再次计费 |
| 本地 RAG | BM25 + 多语言 MiniLM 向量 + RRF；分块、来源、版本、引用 | 当前仅六条短规则，不是大规模企业文档检索 |
| 检索降级 | 索引缺失或过期时退到 BM25，并显示实际后端 | 降级结果不标为向量检索 |
| 证据规则检查 | 引用完整性、币种、部分因果表达与数字存在性提示 | 不保证每个数字与指标的对应关系，也不保证消除所有幻觉 |
| 成本与执行审计 | 模型 Token、缓存输入、工具延迟、请求/调用预算 | 价格未配置时费用未知；调用预算不是固定金额上限 |
| 免费演示 | 预设流程执行真实 SQL，保留图表、引用、历史、导出 | 明确标注非模型生成，不提供任意问题的模型推理 |
| 可复现验收 | 合成数据库、模拟模型响应、恢复/网页测试、固定依赖与离线 CI | 离线验收不等于真实模型回答准确率或生产部署验证 |

## 工作流与检索设计

LangGraph 负责节点状态和检查点恢复。经营工具通过白名单注册入口调用，
与工作流框架解耦。模型只能使用已注册的六个只读工具，参数在执行前校验。

本地多语言嵌入模型避免每次检索调用付费嵌入 API。
BM25 与向量结果通过 RRF 合并，引用包含文档 ID、块号和内容版本哈希。
知识内容变化会使旧索引失效，需要重新构建，避免旧索引与新文档混用。

检索片段作为证据输入，不作为系统指令。
只读工具和规则检查用于降低风险，但不是提示注入或错误业务推断的完备防护。

## 检索对照实验

语料为六条项目内整理的经营规则，当前每条一个块。
24 条中英文查询及标签由项目内编写：
开发集 8 条（6 条相关、2 条无关），留出集 16 条（12 条相关、4 条无关）。
该评测不是外部独立盲测或标准公开基准。

同义词扩展、通用词过滤和相关性门槛是启发式规则，不是训练出的概率。
门槛和通用词修正在开发集上检查。

| 留出集指标 | 原关键词 | BM25 + 同义扩展 | BM25 + 本地向量 + RRF |
|---|---:|---:|---:|
| Hit@3（相关题命中任一标注文档） | 6/12 | 11/12 | 11/12 |
| MRR@3 | 0.5000 | 0.9167 | 0.9167 |
| 无关题正确不返回 | 4/4 | 4/4 | 4/4 |

本实验中混合检索没有超过 BM25，未显示向量检索的额外收益。
本机预热后的中位检索耗时约为 0.4 ms / 0.04 ms / 5.2 ms，
仅为单次小样本测量，不是并发 SLA。

[原始结果](evaluation/retrieval_results.json) 包含每条查询的输出与耗时。
Hit@3 是检索命中指标，不等于回答正确率；四条无关题不足以证明完整拒答能力。

## 模型执行与数据边界

付费模式默认使用 `gpt-5-mini`，模型名称可通过配置调整。
每轮最多 6 次模型请求和 6 次工具调用，每次输出最多 3500 Tokens。
SDK 超时为 45 秒，自动重试为 0；达到预算时返回 `partial` 状态并保留已完成证据。

这些限制控制请求次数和输出长度，不是固定美元上限。
多轮历史仍可能增加输入费用。Token 数量取自接口，缺少 `usage` 时标为未知。
估算费用需配置普通输入、缓存输入和输出单价，最终费用以 API 账单为准。

付费模式使用 `store=True` 和 `previous_response_id`：
问题、检索片段和工具结果会发送至模型 API。免费模式不向模型 API 发送数据。
公开部署前应重新审核数据与存储政策。

## 未实现范围

目前没有公开在线服务、多用户认证、租户隔离或生产级部署。
知识库规模较小，困难问题、真实模型回答质量和并发性能需要进一步验证。
后续工作包括受控部署、更丰富的知识与失败案例，以及更完整的评测。
